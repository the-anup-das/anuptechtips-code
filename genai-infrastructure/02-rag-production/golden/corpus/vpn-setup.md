# VPN setup guide

Every laptop needs the VPN client before it can reach internal tools.

## Install

Install WireGuard from the software center, then import the profile from the device portal.

## Error E1042

Error E1042 means your certificate expired. Renew it in the device portal and reconnect.

## Error E2210

Error E2210 means the clock on your laptop is wrong by more than 5 minutes. Turn on automatic time.
